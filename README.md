# Teto Companion

Primera versión: una mascota flotante estilo Teto que se puede mover por encima de otras aplicaciones.

## Funciones
- Ventana flotante sobre otras apps.
- Se puede arrastrar con el dedo.
- Servicio en primer plano para mantenerla activa.
- Botón para activar/desactivar.

## Para usar tu propia Teto
Reemplaza:
app/src/main/res/drawable/teto_companion.png

por una imagen PNG transparente, manteniendo el mismo nombre.

## Compilación
Abrir el proyecto en MobileStudio/AndroidIDE y ejecutar Build > assembleDebug.
El APK quedará en:
app/build/outputs/apk/debug/app-debug.apk
